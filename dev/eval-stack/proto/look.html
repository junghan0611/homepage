1.1 중첩 섹션도 같은 방식

레벨별 data-level 속성으로 들여쓰기만 CSS가 담당. Hugo/hextra의 목차 자동생성 같은 건 여기 없다 — 정적 마크업 그대로다. 이 섹션은 형제 <details>이지 1번 안에 중첩된 게 아니다 (org 접힘과 1:1은 아님).

2. 접힘(fold) — 헤딩을 클릭해 보라

계약 변경(승인됨): .org-section은 <details class="org-section" data-level="N" open> + <summary class="org-heading">다. JS 없이 접힌다. 아래 두 블록도 같은 엘리먼트다 — 하나는 펼친 채, 하나는 접힌 채로 시작한다.

펼친 채로 시작

이 문단이 보인다 — open 속성. 헤딩을 클릭하면 접힌다.

접힌 채로 시작

이 문단은 open이 없어 시작 시 숨는다. 헤딩을 클릭하면 펼쳐진다. 정적 스냅샷이 아니라 진짜 토글이다.
